# 💰 Personal Budget Management System

A simple and interactive web-based Personal Budget Management System developed using **HTML, CSS, and JavaScript**.

The application helps users record their income and expenses, track their savings, analyse spending patterns, and view financial reports.

## ✨ Features

- Add income and expense transactions
- Categorise transactions
- Edit and delete transactions
- View total income, expenses, savings, and balance
- Store data using browser **Local Storage**
- Smart Budget Insights
- Budget Health Score based on spending percentage
- Identify the biggest expense category
- Weekly and monthly financial reports
- Interactive income, expense, and savings graphs
- Responsive design for desktop and mobile devices

## 🧠 Smart Budget Insights

The system provides simple rule-based insights based on the user's spending:

- Budget Health Score
- Spending percentage of income
- Biggest expense category
- Saving suggestions

> **Note:** The Budget Health Score is a custom rule-based feature created for this project and is not a professional financial assessment.

## 🛠️ Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling and responsive design
- **JavaScript** – Application logic and interactivity
- **Local Storage** – Storing transaction data in the browser

## 📊 Reports

The system provides:

- Weekly income, expenses, and savings
- Monthly income, expenses, and savings
- Interactive graphs for:
  - Income
  - Expenses
  - Savings

Users can switch between weekly and monthly views and select the financial metric they want to analyse.

## 💾 Data Storage

Transaction data is stored using the browser's **Local Storage**.

This means:
- Data remains available after refreshing the page.
- No backend or database is required.
- Data is stored separately on each browser/device.
